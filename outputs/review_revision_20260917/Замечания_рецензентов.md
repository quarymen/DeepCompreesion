## Основные вопросы

- **Надёжность оценки:** случайное разделение соседних кадров может завышать качество на новых датах и условиях.
- **Справедливость сравнения:** одинаковая latent dimension не означает одинаковый объём хранения. Нужно отдельно разобраться с результатами TT-SVD.
- **Полнота экспериментов:** нужны контролируемые абляции attention, более широкая проверка устойчивости результатов и измерения вычислительных затрат.
- **Воспроизводимость и интерпретация:** необходимо уточнить нормализацию, настройки WRF-Chem, гиперпараметры и пределы выводов о времени и обратных задачах.

<summary>Оригинал замечания (EN)</summary>

The manuscript does not clearly report which simulation dates and how many samples are included in the training, validation, and test datasets. It is also unclear whether the five-fold cross-validation is performed by individual time frames, complete dates, or complete simulation scenarios. The publicly available code currently uses a random frame-level split, in which a fraction of the combined 10 min outputs is randomly selected for validation or evaluation. Consecutive atmospheric concentration fields separated by only 10 min are likely to be strongly correlated. As a result, samples from the same day, or even from adjacent times, may appear in both the training and validation datasets. In this case, the reported performance may mainly reflect interpolation within already observed meteorological conditions rather than generalization to new dates or new atmospheric conditions. The authors should provide a more detailed description of the data-splitting procedure and explain whether the temporal dependence among consecutive samples has been considered.

**Приоритет:** P1. **Тип работы:** Методика + эксперименты. **Раздел:** Methods; Compression ratio; Results.

**Связанные пункты:** R2-4; R2-5; R2-2.

**Выполненные правки и доказательства:** —

**Ответ рецензенту (EN):** —

<details>
<summary>Оригинал замечания (EN)</summary>

Using the same nominal “latent dimension” does not necessarily provide a fair comparison among the tested methods because the actual information that must be stored differs substantially between them. In the public implementation, DCT and wavelet compression select the coefficients with the largest absolute values separately for each sample. Therefore, the positions of the retained coefficients must be stored in addition to their values, whereas the current compression ratio mainly counts the number of retained coefficients. Because these positions change from one sample to another, this implementation of DCT also differs from the fixed linear projection described in the manuscript. PCA requires storage of the mean and basis matrix, while an autoencoder requires storage of the network parameters. UMAP requires the fitted embedding model, and the inverse transformation in the current implementation is performed using a KNN regressor. This also requires the latent training points and their corresponding full high-dimensional target fields to be retained, which may result in a substantial storage cost. The authors should compare the methods using actual bytes or bits per grid value and present the relationship between reconstruction error and actual storage cost. They should also state whether fixed costs such as model weights or basis matrices are shared across many time frames. If the main purpose is file compression, quantization and actual encoded file sizes should also be considered. If the main purpose is reduced-state representation for inverse modelling, less emphasis should be placed on file compression ratios and more attention should be given to online computational cost and downstream inverse-modelling applications.

</details>

## Вводные оценки рецензентов

<details>
<summary>Reviewer 1 — вводная оценка (EN)</summary>

This manuscript evaluates several dimensionality-reduction methods for three-dimensional carbon monoxide concentration fields simulated by WRF-Chem over the Novosibirsk urban area. The tested methods include PCA, DCT, wavelet compression, interpolation, truncated SVD, random projection, UMAP, Tensor-Train decomposition, and three-dimensional convolutional autoencoders. The authors further introduce a lightweight spatial attention module, SAM3D, into a plain 3D convolutional autoencoder. The study addresses a relevant practical problem because large atmospheric chemistry simulations generate substantial amounts of three-dimensional data, while inverse modelling and data assimilation may require these data to be processed repeatedly. The manuscript has several strengths. It compares a relatively broad range of methods, uses a plain 3D-CAE with a similar architecture as a direct baseline, evaluates reconstruction using MSE, relative L2 error, and SSIM, and further examines the local sensitivity of the encoder through Jacobian norms. The results show that SAM3D performs better than the plain 3D-CAE at all tested latent dimensions and outperforms several main linear methods at latent dimensions of 16, 32, and 64. However, several parts of the manuscript still require further clarification, particularly the data-splitting strategy, interpretation of the temporal dimension, parameter selection, computational efficiency, description of the WRF-Chem simulations, fairness of the comparison among different reduction methods, and coverage of related studies. These issues affect the interpretation of the reported performance and the reliability of the comparison. I therefore recommend major revision before the manuscript is considered for publication.

</details>
